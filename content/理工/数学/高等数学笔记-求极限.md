# 高等数学笔记：求极限

## 一、求极限的依据

**【依据 1】极限的四则运算法则**

设 $\lim\limits_{x\to a} f(x) = A$，$\lim\limits_{x\to a} g(x) = B$ 均存在，则有：

1. $\lim\limits_{x\to a}\left[kf(x) \pm lg(x)\right] = k\lim\limits_{x\to a} f(x) \pm l\lim\limits_{x\to a} g(x) = kA \pm lB$
2. $\lim\limits_{x\to a}\left[f(x)\cdot g(x)\right] = A\cdot B$
3. $\lim\limits_{x\to a}\dfrac{f(x)}{g(x)} = \dfrac{\lim\limits_{x\to a} f(x)}{\lim\limits_{x\to a} g(x)} = \dfrac{A}{B}\ (B\neq 0)$

> 注：不存在 ± 不存在 = 不一定；四则运算法则只适用于有限次运算的情形，对无限次运算不适用。

**【依据 2】** 连续点处极限等于函数值，即 $\lim\limits_{x\to a} f(x) = f(a)$

**【依据 3】** 初等函数在定义区间内处处连续

**例 1**

1. $\lim\limits_{x\to 1}\dfrac{x-3}{x^2-9} = \dfrac{1-3}{1-9} = \dfrac{1}{4}$（直接代入）
2. $\lim\limits_{x\to 3}\dfrac{x-3}{x^2-9} = \lim\limits_{x\to 3}\dfrac{1}{x+3} = \dfrac{1}{6}$（约去零因子）
3. $\lim\limits_{x\to -3}\dfrac{x-3}{x^2-9} = \infty$

## 二、七种未定式

> 除此七种外，都可安全代入求极限。

| 未定式 | 例子 |
| ---- | ---- |
| $\dfrac{0}{0}$ | $\lim\limits_{x\to 0}\dfrac{\sin x}{x}=1$；$\lim\limits_{x\to 0}\dfrac{x\sin\frac{1}{x}}{x}$；$\lim\limits_{x\to 0}\dfrac{x}{x^2}=\infty$ |
| $\dfrac{\infty}{\infty}$ | $\lim\limits_{x\to\infty}\dfrac{x^2+x}{x^2+2x}$ |
| $0\cdot\infty$ | $\lim\limits_{x\to\infty} x\ln\left(1+\dfrac{1}{x}\right)$ |
| $\infty-\infty$ | $\lim\limits_{x\to 0}\left(\dfrac{1}{x}-\dfrac{1}{\sin x}\right)$ |
| $1^{\infty}$ | $\lim\limits_{x\to 0}(1+x)^{\frac{1}{x}}$ |
| $\infty^{0}$ | $\lim\limits_{x\to\infty} x^{\frac{1}{x}}$ |
| $0^{0}$ | $\lim\limits_{x\to 0^+} \sin x^{\tan x}$ |

## 三、等价无穷小替换

### 1. 常用等价无穷小（熟记以下四组公式！）

当 $x\to 0$ 时：

- **①** $\sin x \sim x$，$\tan x \sim x$，$\arcsin x \sim x$，$\arctan x \sim x$，$e^x-1 \sim x$，$\ln(1+x) \sim x$
- **②** $a^x - 1 \sim x\ln a$；$(1+x)^{\alpha}-1 \sim \alpha x\ (\alpha\in\mathbb{R})$
- **③** $1-\cos x \sim \dfrac{1}{2}x^2$；$x-\ln(1+x) \sim \dfrac{1}{2}x^2$
- **④** $x-\sin x \sim \dfrac{1}{6}x^3$；$x-\arcsin x \sim -\dfrac{1}{6}x^3$；$x-\tan x \sim -\dfrac{1}{3}x^3$；$x-\arctan x \sim \dfrac{1}{3}x^3$

### 2. 等价无穷小替换的用法

1. 使用时通常将 $x$ 广义化为趋于 0 的函数（无穷小量）；
2. 只有整个函数的乘除因子才能用等价无穷小替换，加减项一般不能替换。

**例 2　计算下列极限**

**(1)** $\lim\limits_{x\to 0}\dfrac{x-\sin x}{(1-\cos x)\tan x} = \lim\limits_{x\to 0}\dfrac{\frac{1}{6}x^3}{\frac{1}{2}x^2\cdot x} = \dfrac{1}{3}$

**(2)** $\lim\limits_{x\to 0}\left(\dfrac{1}{x\sin x}-\dfrac{1}{x\tan x}\right)$（$\infty-\infty$ 型）

解：原式 $= \lim\limits_{x\to 0}\dfrac{1-\cos x}{x\sin x} = \lim\limits_{x\to 0}\dfrac{\frac{1}{2}x^2}{x^2} = \dfrac{1}{2}$

**【等价无穷小替换 + 拆极限 = 王炸！】**

**(3)** $\lim\limits_{x\to 0}\dfrac{\ln(1+2x^2)+\ln(1-x^2)}{x\sin x}$

解：原式 $= \lim\limits_{x\to 0}\dfrac{\ln(1+2x^2)}{x\sin x} + \lim\limits_{x\to 0}\dfrac{\ln(1-x^2)}{x\sin x} = \lim\limits_{x\to 0}\dfrac{2x^2}{x^2} + \lim\limits_{x\to 0}\dfrac{-x^2}{x^2} = 2-1 = 1$

## 四、拆极限

**例 3　下列各极限拆对了？拆错了？还是不一定？**

1. $\lim\limits_{x\to 0}\dfrac{x-\sin x}{x^3} = \lim\limits_{x\to 0}\dfrac{x}{x^3} - \lim\limits_{x\to 0}\dfrac{\sin x}{x^3}$　✗（两项均不存在，不能拆）
2. $\lim\limits_{x\to 0}\dfrac{\sin x + x^2\cos\frac{1}{x}}{x} = \lim\limits_{x\to 0}\dfrac{\sin x}{x} + \lim\limits_{x\to 0}\dfrac{x^2\cos\frac{1}{x}}{x}$　✓
3. $\lim\limits_{x\to 0}\dfrac{1-\cos x + xf(x)}{x^2} = \lim\limits_{x\to 0}\dfrac{1-\cos x}{x^2} + \lim\limits_{x\to 0}\dfrac{xf(x)}{x^2}$　✓

**拆极限的原则**

1. 若拆开后，两项极限都不存在，则不能拆；
2. 若拆开后，两项极限都存在，则可以拆（但是，有精神内耗！）。

拆极限的理论依据——在任何情况下，看到存在就拆出。

**拆极限的终极原则**

1. 若拆开后，两项极限都不存在，则不能拆；
2. 在任何情况下，看到存在就拆出。

**提前求**：整个函数乘除因子 + 极限非 0 → 提前求（求出）。

**例 4　此处可以提前求极限吗？**

**(1)** $\lim\limits_{x\to 0}\dfrac{x\cos x}{\sin x} = \lim\limits_{x\to 0}\dfrac{x}{\sin x} = 1$（$\cos x\to 1$，非零因子提前求出）

**(2)** $\lim\limits_{x\to 1}\left(\dfrac{x}{x-1}-\dfrac{1}{\ln x}\right)$（思维：$x\to 1$ 时换元）

解：原式 $= \lim\limits_{x\to 1}\dfrac{x\ln x-(x-1)}{(x-1)\ln x} = \lim\limits_{x\to 1}\dfrac{x\ln x-(x-1)}{(x-1)^2}$，令 $x-1=t$，

$$=\lim\limits_{t\to 0}\dfrac{(t+1)\ln(t+1)-t}{t^2} = \lim\limits_{t\to 0}\dfrac{t\ln(t+1)}{t^2} + \lim\limits_{t\to 0}\dfrac{\ln(t+1)-t}{t^2} = \lim\limits_{t\to 0}\dfrac{t^2}{t^2} + \lim\limits_{t\to 0}\dfrac{-\frac{1}{2}t^2}{t^2} = 1+\left(-\dfrac{1}{2}\right) = \dfrac{1}{2}$$

## 五、洛必达法则

**洛必达法则**　设函数 $f(x), F(x)$ 满足条件：（$\frac{0}{0}$ 型或 $\frac{\infty}{\infty}$ 型）

1. 当 $x\to a$ 时，函数 $f(x)$ 及 $F(x)$ 都趋于 0（或都趋于 $\infty$）；
2. 在点 $a$ 的某去心邻域内，$f'(x)$ 及 $F'(x)$ 都存在且 $F'(x)\neq 0$；
3. $\lim\limits_{x\to a}\dfrac{f'(x)}{F'(x)}$ 存在（或为 $\infty$），

那么 $\lim\limits_{x\to a}\dfrac{f(x)}{F(x)} = \lim\limits_{x\to a}\dfrac{f'(x)}{F'(x)}$。

> 注：以上对于 $x\to\infty$ 也适用。

**例 5　计算下列极限**

**(1)** $\lim\limits_{x\to 3}\dfrac{x-3}{x^2-9}\ \left(\frac{0}{0}\right) = \lim\limits_{x\to 3}\dfrac{1}{2x} = \dfrac{1}{6}$

**(2)** $\lim\limits_{x\to 0}\dfrac{e^{x^2}-e^{2-2\cos x}}{x^4}$（提出后者）

解：原式 $= \lim\limits_{x\to 0}\dfrac{e^{2-2\cos x}\left(e^{x^2-2+2\cos x}-1\right)}{x^4} = \lim\limits_{x\to 0}\dfrac{x^2-2+2\cos x}{x^4} = \lim\limits_{x\to 0}\dfrac{2x-2\sin x}{4x^3} = \dfrac{1}{2}\lim\limits_{x\to 0}\dfrac{x-\sin x}{x^3} = \dfrac{1}{2}\times\dfrac{1}{6} = \dfrac{1}{12}$

## 六、$1^{\infty}$ 型（幂指函数，另含 $\infty^0$、$0^0$）

**【方法一】重要极限**

$$\lim\limits_{x\to\infty}\left(1+\dfrac{1}{x}\right)^x = e$$

变形：$\lim\limits_{\square\to\infty}\left(1+\dfrac{1}{\square}\right)^{\square} = e$，$\lim\limits_{x\to 0}(1+x)^{\frac{1}{x}} = e$

**例 6**　设 $\lim\limits_{x\to\infty}\left(1+\dfrac{k}{x}\right)^{2x} = e$，则 $k = \dfrac{1}{2}$（凑倒数：$e^{2k}=e$）

**例 7**　$\lim\limits_{x\to 0}\left[\dfrac{\ln(1+x)}{x}\right]^{\frac{1}{e^x-1}}$（凑倒数）

解：原式 $= \lim\limits_{x\to 0}\left[1+\dfrac{\ln(1+x)-x}{x}\right]^{\frac{x}{\ln(1+x)-x}\cdot\frac{\ln(1+x)-x}{x(e^x-1)}} = e^{\lim\limits_{x\to 0}\frac{-\frac{1}{2}x^2}{x^2}} = e^{-\frac{1}{2}}$

> 注：若 $\lim u(x) = A>0$，$\lim v(x) = B$，则 $\lim u(x)^{v(x)} = A^B$。

**【方法二】吟唱**："e 的极限符号往里走，指函数抄一遍，再乘底减 1"（$\infty^0$、$0^0$ 型取对数 $\ln$ 底）

$$\lim u^v = \lim e^{\ln u^v} = e^{\lim v\ln u} = e^{\lim v(u-1)}$$

**【例 7 再解】** 原式 $= e^{\lim\limits_{x\to 0}\frac{1}{e^x-1}\left[\frac{\ln(1+x)}{x}-1\right]} = e^{\lim\limits_{x\to 0}\frac{\ln(1+x)-x}{(e^x-1)x}} = e^{\lim\limits_{x\to 0}\frac{-\frac{1}{2}x^2}{x^2}} = e^{-\frac{1}{2}}$

**【练】** $\lim\limits_{x\to 0}\left(\dfrac{1+x}{1-x}\right)^{\frac{1}{x}}$

解：原式 $= e^{\lim\limits_{x\to 0}\frac{1}{x}\ln\frac{1+x}{1-x}} = e^{\lim\limits_{x\to 0}\frac{1}{x}\left(\frac{1+x}{1-x}-1\right)} = e^{\lim\limits_{x\to 0}\frac{2x}{x(1-x)}} = e^2$

## 七、练一练

**1.** $\lim\limits_{x\to 0}\dfrac{\ln(1-\arctan 2x)+x^2}{\sqrt{1+x}-1}$

解：原式 $= \lim\limits_{x\to 0}\dfrac{\ln(1-\arctan 2x)}{\frac{1}{2}x} + \lim\limits_{x\to 0}\dfrac{x^2}{\frac{1}{2}x} = \lim\limits_{x\to 0}\dfrac{-2x}{\frac{1}{2}x} + 0 = -4$

**2.** $\lim\limits_{x\to 0}\dfrac{\sin x - x\cos x}{x^3}$

- （法一）原式 $= \lim\limits_{x\to 0}\dfrac{\cos x(\tan x - x)}{x^3} = \lim\limits_{x\to 0}\dfrac{\frac{1}{3}x^3}{x^3} = \dfrac{1}{3}$
- （法二·洛必达）原式 $= \lim\limits_{x\to 0}\dfrac{\cos x - \cos x + x\sin x}{3x^2} = \lim\limits_{x\to 0}\dfrac{x^2}{3x^2} = \dfrac{1}{3}$

**3.** $(a>0,\ b>0,\ c>0)$　$\lim\limits_{n\to\infty}\left[\dfrac{a^{\frac{1}{n}}+b^{\frac{1}{n}}+c^{\frac{1}{n}}}{3}\right]^n$

解：原式 $= e^{\lim\limits_{n\to\infty} n\left[\frac{1}{3}\left(a^{\frac{1}{n}}+b^{\frac{1}{n}}+c^{\frac{1}{n}}\right)-1\right]} = e^{\lim\limits_{n\to\infty}\frac{\left(a^{\frac{1}{n}}-1\right)+\left(b^{\frac{1}{n}}-1\right)+\left(c^{\frac{1}{n}}-1\right)}{3\cdot\frac{1}{n}}}$

$$= e^{\frac{1}{3}\lim\limits_{n\to\infty}\left(\frac{1}{n}\ln a+\frac{1}{n}\ln b+\frac{1}{n}\ln c\right)\big/\frac{1}{n}} = e^{\frac{1}{3}(\ln a+\ln b+\ln c)} = e^{\frac{1}{3}\ln abc} = (abc)^{\frac{1}{3}}$$

## 八、【小技巧】"和取低阶"

$\alpha\to 0$，则 $\alpha + o(\alpha) \sim \alpha$，其中 $o(\alpha)$ 是高阶无穷小。

验证：$\lim\limits_{\alpha\to 0}\dfrac{\alpha+o(\alpha)}{\alpha} = \lim\limits_{\alpha\to 0}\dfrac{\alpha}{\alpha} + \lim\limits_{\alpha\to 0}\dfrac{o(\alpha)}{\alpha} = 1$，即分子与分母是等价无穷小。

**举例**：$x\to 0$ 时，$x + 2x^3 + x^5 + o(x^5) \sim x$（取最低阶！）

**（简洁解法）** $\lim\limits_{x\to 0}\dfrac{\ln(1-\arctan 2x)+x^2}{\sqrt{1+x}-1}$：$x^2$ 看作 $o(x)$，略去！分子 $\sim -2x + x^2 \sim -2x$

$$= \lim\limits_{x\to 0}\dfrac{\ln(1-\arctan 2x)}{\frac{1}{2}x} = \lim\limits_{x\to 0}\dfrac{-2x}{\frac{1}{2}x} = -4$$
