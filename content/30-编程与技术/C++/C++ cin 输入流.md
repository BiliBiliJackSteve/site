# C++ cin 输入流

## cin 是什么？为什么能用 `.`？

`cin` 不是关键字，而是 C++ 标准库里的一个**对象**（`istream` 类的实例，定义在 `<iostream>`）。

`.` 是**成员访问运算符**——和结构体/类一样，对象通过 `.` 调用自己的成员函数：

```cpp
cin.peek();   // 调用 cin 这个对象的 peek() 成员函数
cin.get();    // 调用 get() 成员函数
```

类比：`cin` 像一台"输入机器"，`.` 后面跟的是这台机器的各种"功能按钮"。

## 三种读取方式的对比

| 操作 | 行为 |
| ---- | ---- |
| `cin >> x` | 取走（跳过空白字符） |
| `cin.get()` | 取走（一个字符，包括空格和 `'\n'`） |
| `cin.peek()` | **只看，不取走** |

```cpp
char c = cin.peek();   // 看下一个字符是什么，但它还留在输入流里
```

## 常用成员一览

```cpp
cin.get()              // 读一个字符（包括空格和'\n'），返回该字符
cin.get(ch)            // 读一个字符存进 ch
cin.getline(str, 100)  // 读一整行（最多99字符）到字符数组，遇'\n'停止并丢弃它
cin.peek()             // 偷看下一个字符，不取走
cin.putback(ch)        // 把一个字符塞回输入流
cin.ignore()           // 丢弃1个字符
cin.ignore(100, '\n')  // 丢弃直到遇到'\n'（常用于清空输入残留）
cin.eof()              // 是否到达文件/输入末尾（返回 bool）
cin.fail()             // 输入是否出错（如该输数字却输了字母）
cin.good()             // 流状态是否正常
cin.clear()            // 清除错误状态标记（输入出错后恢复用）
cin.gcount()           // 上次操作实际读了多少个字符
```

## 常见组合用法

**`>>` 之后接 `getline` 前，清掉残留的回车：**

```cpp
cin >> x;
cin.ignore(100, '\n');   // 否则 getline 会立刻读到空行
cin.getline(str, 100);
```

**输入出错后恢复：**

```cpp
if (cin.fail()) {
    cin.clear();            // 清除错误标记
    cin.ignore(100, '\n');  // 丢掉错误输入
}
```

**读个数未知的一行数据：**

```cpp
while (cin.peek() != '\n') {
    cin >> x;   // 详见 [[C++ 栈、堆与动态数组]] 中的动态数组输入
}
```
