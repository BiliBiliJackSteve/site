# C++ 高精度乘法（洛谷 P1303）

> 来源：洛谷 P1303（高精度乘法）的调试与优化记录。初版因"部分积未错位"WA，修正后 AC，最终重写为经典的"竖式累加 + 统一进位"写法。

## 题目要点

- 输入两个非负整数（可达约 2000 位），输出乘积
- 远超 `long long` 范围，需手写高精度乘法

## 初版代码（WA）

思路：字符串逆序存储（低位在前），用 `a` 的每一位乘 `b` 得到部分积 `temp`，再把部分积累加进 `result`。

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <cmath>
using namespace std;

string iinput()
{
    string temp;
    cin >> temp;
    reverse(temp.begin(), temp.end());
    return temp;
}

int main()
{
    string a, b, result;
    int plus = 0;

    a = iinput();
    b = iinput();

    if (a.size() > b.size())
    {
        string temp;
        temp = a;
        a = b;
        b = temp;
    }

    for (int i = 0; i < a.size(); i++)
    {
        string temp, temp1;
        temp1 = result;
        result.clear();
        for (int j = 0; j < b.size(); j++)
        {
            int sum = (i < a.size() ? a[i] - '0' : 0) * (j < b.size() ? (b[j] - '0') : 0) + plus;
            temp.push_back('0' + sum % 10);
            plus = sum / 10;
        }
        if (plus)
        {
            temp.push_back('0' + plus);
        }
        plus = 0;

        int plus1 = 0;
        for (int k = 0; k < max(temp1.size(), temp.size()); k++)
        {
            int sum1 = (k < temp1.size() ? temp1[k] - '0' : 0) + (k < temp.size() ? (temp[k] - '0') : 0) + plus1;
            result.push_back('0' + sum1 % 10);
            plus1 = sum1 / 10;
        }
        if (plus1)
        {
            result.push_back('0' + plus1);
        }
    }
    if (plus)
    {
        result.push_back('0' + plus);
    }
    reverse(result.begin(), result.end());
    for (int i = 0; result[i] != '\0'; i++)
    {
        if (result[i] == '0' && result[i + 1] != '\0')
        {
            result.erase(i, 1);
            i == 0 ? i = 0 : i--;
        }
        else
        {
            break;
        }
    }
    cout << result << endl;
    return 0;
}
```

## 问题分析

### 1. 核心算法错误：部分积没有错位 ❌

这是导致结果错误的根本原因。思路是用 `a` 的每一位 `a[i]` 去乘 `b` 得到部分积 `temp`，再累加进 `result`，但**每次累加前没有把部分积左移 i 位**（在"低位在前"的存储方式下，应给 `temp` 前面补 i 个 `'0'`，或在累加时从第 i 位开始对齐）。

实际效果相当于：

```
result = (a[0]*b) + (a[1]*b) + ... + (a[n-1]*b)   // 没有乘 10^i
```

验证：输入 `12 34`，期望 `408`：

- 第 1 轮：`2 * 34 = 68` → `result = 68`
- 第 2 轮：`1 * 34 = 34`（应为 340）→ `result = 68 + 34 = 102` ❌

### 2. 去前导零的循环有 off-by-one 错误 ❌

```cpp
if (result[i] == '0' && result[i + 1] != '\0')
{
    result.erase(i, 1);
    i == 0 ? i = 0 : i--;   // 问题在这里
}
```

删除位置 `i` 的字符后，下一个字符会移动到位置 `i`，所以应该重新检查位置 `i`，即统一执行 `i--`（`i` 变成 -1，循环 `i++` 后回到 0）。而现在 `i == 0` 时被设为 0，经 `i++` 后跳到 1，跳过了新的 `result[0]`。

后果：连续两个以上前导零删不干净。例如 `0 * 100`：

- 计算得到 `result = "000"`（逆序后仍是 `"000"`）
- 只删了一个就变成 `"00"` 并跳出，输出 `"00"` ❌（应为 `"0"`）

### 3. 死代码

主循环后的 `if (plus) { result.push_back('0' + plus); }`：`plus` 在每轮末尾已被重置为 0，此处恒为假，永远不会执行。

### 4. 冗余判断

`i < a.size() ? a[i] - '0' : 0`：外层循环已保证 `i < a.size()`，三元判断恒取前者，属于无用代码（大概是想模仿内层对 `j` 的写法）。

### 5. 其他小问题（不影响正确性，但值得注意）

- **效率**：每轮 `temp1 = result` 整体拷贝字符串、`erase` 逐字符删除，时间复杂度偏高。2000 位规模下 O(n²) 可过，但写法不够简洁。
- **脆弱写法**：`result[i + 1]` 依赖取到 `'\0'`（C++11 起 `s[s.size()]` 合法返回 `'\0'`，所以能工作，但可读性差）。
- `int` 与 `size_t` 混用比较（`i < a.size()`），会产生编译警告。

## 修正方案（AC）

针对上面两个核心问题，只需两处修改：

**修改 1：部分积累加前补 i 个前导零，实现错位**

```cpp
// 在部分积 temp 计算完毕、累加进 result 之前：
for (int j = 0; j < i; j++)
{
    temp.insert(0, "0");
}
```

**修改 2：去前导零循环统一 `i--`**

```cpp
if (result[i] == '0' && result[i + 1] != '\0')
{
    result.erase(i, 1);
    i--;                 // 删除后重查同一位置，i 可为 -1，i++ 后回到 0
}
else
{
    break;
}
```

同时删除死代码 `if (plus) result.push_back(...)`（主循环后那一段）。

## 进一步优化：竖式累加 + 统一进位

### 结构上的问题（为什么代码又长又复杂）

修正后的思路仍是：每算一个部分积 → 转成字符串 → 错位 → 再做一次完整的大数加法。这导致：

- 外层每轮都要维护两个进位变量（`plus`、`plus1`）；
- `temp1 = result` 每轮整串拷贝；
- `temp.insert(0, "0")` 逐字符插入，每次插入都是 O(len)，累计 O(n³) 级别开销；
- 最后还要专门写一段容易出错的前导零删除。

根本原因是**用字符串中间态反复做"乘法 + 加法"两套逻辑**。经典写法只用一个 `int` 数组，乘法累加和进位分离，一次到位。

### 优化思路

核心思想：**第 i 位 × 第 j 位的贡献天然落在结果的 i+j 位上**，直接累加进数组，不进位，最后统一扫一遍进位。这样：

- 不需要错位（`i+j` 下标就是错位）；
- 不需要中间字符串、不需要每轮大数加法；
- 不需要 `plus` / `plus1` 两个进位变量；
- 前导零处理只需从后找第一个非零位。

### 优化后代码

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <algorithm>
using namespace std;

int main()
{
    string a, b;
    cin >> a >> b;
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());

    vector<int> c(a.size() + b.size(), 0);

    // 竖式累加，不进位
    for (int i = 0; i < (int)a.size(); i++)
        for (int j = 0; j < (int)b.size(); j++)
            c[i + j] += (a[i] - '0') * (b[j] - '0');

    // 统一进位
    for (int i = 0; i + 1 < (int)c.size(); i++)
    {
        c[i + 1] += c[i] / 10;
        c[i] %= 10;
    }

    // 去前导零并输出
    int p = c.size() - 1;
    while (p > 0 && c[p] == 0) p--;
    for (; p >= 0; p--) cout << c[p];
    cout << endl;
    return 0;
}
```

## 经验总结

- 高精度乘法中，**第 i 位 × 第 j 位的贡献落在结果的第 i+j 位**，用数组下标天然完成错位，无需显式移位
- **累加与进位分离**：先全部累加，最后统一进位，避免维护多个进位变量
- 用 `int` 数组作中间态，比字符串反复"乘法 + 加法"更简洁高效
- 删除前导零时注意 off-by-one：`erase(i, 1)` 后应统一 `i--` 重查当前位置
- 竖式乘法是"边乘边加"的合并过程，分开模拟（先乘出每个部分积再相加）容易在错位上出错
- 有关动态数组以及vector的内容见[[C++ 栈、堆与动态数组]]
