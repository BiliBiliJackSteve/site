# C++ 指针交换两个变量（swap）

## 问题

如何写一个 void 函数，只通过传指针来交换两个变量的值？

## 核心思路

C/C++ 是**值传递**：直接把变量传给函数，函数内交换的只是副本，原变量不会变。

解决方法：传变量的**地址（指针）**，函数就能通过地址直接修改原变量的内存内容。

## 代码实现

```cpp
#include <stdio.h>

// 用指针接收两个变量的地址
void swap(int *a, int *b) {
    int temp = *a;   // temp 保存 a 指向的值
    *a = *b;         // 把 b 指向的值写入 a 指向的内存
    *b = temp;       // 把 temp 写入 b 指向的内存
}

int main() {
    int x = 10, y = 20;

    printf("交换前: x = %d, y = %d\n", x, y);
    swap(&x, &y);    // 传地址，而不是传值
    printf("交换后: x = %d, y = %d\n", x, y);

    return 0;
}
```

输出：

```
交换前: x = 10, y = 20
交换后: x = 20, y = 10
```

## 关键点解析

| 写法      | 含义                    |
| ------- | --------------------- |
| `int *a` | 形参是整型指针，接收地址          |
| `&x`    | 取 x 的地址传入函数           |
| `*a`    | 解引用，读写 a 所指向内存中的值     |

## 常见错误对比

❌ 错误：只传值（交换无效）

```cpp
void swap(int a, int b) {  // a、b 是副本
    int temp = a;
    a = b;
    b = temp;              // 只改了副本，函数返回后丢失
}
```

❌ 错误：交换指针本身（也无效）

```cpp
void swap(int *a, int *b) {
    int *temp = a;
    a = b;
    b = temp;              // 只交换了指针副本的指向，没动指向的值
}
```

✅ 正确：通过指针操作指向的值（`*a` 和 `*b`）

## 记忆口诀

> 要改外面变量的值，就传地址进去，用 `*` 操作内容。

## 扩展

想交换其他类型（`float`、`double`、结构体等），只需把指针类型对应换掉即可；也可以用 `void *` 泛型指针配合 `memcpy` 写通用交换函数。
