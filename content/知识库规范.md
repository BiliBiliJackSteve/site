# 📏 知识库规范

⬅️ 返回 [[index|主页]]

## 文件夹结构

| 文件夹     | 用途                      |
| ------- | ----------------------- |
| `理工/`   | 数学、专业课、考试相关             |
| `语言/`   | 日语、英语（按语言分子文件夹）         |
| `编程/`   | 编程语言、工具、项目              |
| `生活管理/` | 计划、习惯、整理、复盘             |
| `附件/`   | 图片等附件（Obsidian 已配置自动归入） |

编号前缀保证文件夹按领域顺序排列。每个领域文件夹顶部有一个 `XX MOC.md`，作为该领域的内容地图。

## 命名约定

- 笔记名用**清晰的中文短语**，直接表达内容，如 `排列与逆序数`
- MOC 命名为 `领域名 MOC.md`
- 避免日期开头的文件名（日记除外，由 Daily Notes 插件管理）

## 标签约定

标签用于**跨文件夹的主题归类**，与文件夹互补：

- `#数学/线性代数`、`#数学/高等数学`
- `#学业/电路`（其他专业课同理：`#学业/科目名`）
- `#语言/日语`、`#语言/英语`
- `#编程/语言名`、`#编程/工具`（语言名含特殊字符时需转写：C++ → `#编程/cpp`，C# → `#编程/csharp`）
- `#生活/计划`、`#生活/整理`
- 元标签：`#MOC`（内容地图）、`#规范`

原则：**少而精**，一个新标签要先想"以后会用它检索吗"，不会就不加。

## 工作流

1. **新建笔记** → 放入对应领域文件夹
2. **登记** → 在所属 MOC 中添加一条链接（必要时加一句话说明）
3. **打标签** → 1~3 个主题标签即可
4. **定期复盘** → 每周浏览一次 MOC，清理孤立笔记

## 文件操作规定
- 所有的文件操作只允许在content/文件夹内。文件夹外的内容不要动
