# 电路学习路线图

> 目标不是"先学完《电路》和高数再开始 PCB"，而是**以做出第一个成品为主线，按需学习理论**。
>
> 总顺序：**电路基础 → 单片机与 C 语言 → 传感器和通信接口 → 原理图设计 → PCB 设计 → 焊接调试 → 迭代完善**
>
> 每周投入 8～10 小时，通常 6～10 周可完成第一块简单 PCB。不要追求第一次就画复杂主板，先把完整流程走通。

## 一、第一条项目路线：温湿度采集器扩展板

- 使用现成的单片机开发板或主控模块，不一开始就独立设计最小系统
- 接一个 I²C 温湿度传感器
- 可选 OLED 显示、按键、状态指示灯
- 使用 USB 提供的低压电源
- 第一版主要负责电源分配、模块连接、传感器安装和接口引出

分三次完成：

1. **面包板或杜邦线验证功能**：程序能读取传感器并显示、打印数据
2. **画原理图和 PCB**：把杂乱的连线变成一块扩展板
3. **焊接、测试、修改**：做出第二版，修正封装、接口位置、供电和结构问题

好处：既能体验物联网产品开发，又能避开第一块板就遇到晶振、射频、Flash、启动电路等复杂问题。

> ⚠️ 前期只做安全低压直流项目，不碰市电，暂不建议自行设计锂电池充电电路。

## 二、邱关源《电路》（第六版）怎么学

不建议从第一页开始平均用力，按做 PCB 的需要分三个优先级。

### 第一块板之前必须掌握

- 电压、电流、功率、参考方向
- 电阻、电容、电感的基本特性
- 欧姆定律、基尔霍夫电流定律和电压定律（KCL/KVL）
- 串并联、分压、分流、等效电阻
- 节点电压法、网孔电流法
- 独立电源和简单的受控源概念
- RC 一阶电路、时间常数和充放电过程

对应的实际能力：会算 LED 限流电阻；会判断芯片/模块供电是否正确；会分析分压、上拉、下拉电路；能理解复位电路、延时、电源上升过程和简单 RC 滤波；看原理图时知道电流从哪里来、经过什么、回到哪里。

RC 电路重点理解时间常数 $\tau = RC$（充放电变化的快慢）；之后学低通滤波器时再理解截止频率 $f_c=\dfrac{1}{2\pi RC}$。

### 第一块板完成后再学习

正弦稳态电路和相量法、阻抗与导纳、交流功率、频率响应和谐振、简单滤波器、二阶动态电路、耦合电感和变压器基础。

这些对后续学模拟电路、开关电源、电机、射频和信号完整性很重要，但不是第一块扩展板的前置条件。

### 暂时不用深入

三相电路、较复杂的非正弦周期电路、高级网络分析等，先按课程要求学即可。

### 推荐的学习闭环

1. **看概念和例题**：明确它解决什么问题
2. **独立做少量习题**：重点是建模和列方程，不是大量刷题
3. **做一次仿真或实物测量**：例如 RC 充放电、分压、LED 限流
4. **联系自己的项目**：说明这个知识会出现在原理图的哪个位置

> ⚠️ 《电路》主要教**分析**电路，不会完整教选芯片、读数据手册、定封装和布局布线——这些必须另外学。

## 三、高等数学怎么配合

高数重要，但**不要等学完再开始硬件**，前期并行，先掌握与电路直接相关的部分。

### 第一阶段：先补齐

- 函数、指数函数、对数函数 → 电容充放电和指数变化
- 科学计数法和单位换算 → 毫、微、纳、皮等单位
- 方程与方程组 → 节点法和网孔法列方程
- 复数的基本运算 → 后续相量法与阻抗分析
- 导数的意义和基本计算 → 用变化率描述动态电路
- 积分的基本意义、简单一阶微分方程 → 理解 RC、RL 电路

### 第二阶段：项目做完后再深入

多元函数与多元微积分、级数、傅里叶级数及频域思想、拉普拉斯变换、线性代数、概率论与数理统计。

其中线性代数、复变与积分变换、概率统计对信号处理、通信、控制和物联网数据分析很有价值，但不影响先做一块简单 PCB。

> 💡 学高数时多问一句："这个数学对象在工程里表示什么？"导数不仅是切线斜率，也是电流电压变化的快慢；积分不仅是面积，也可以表示电荷的累积。

## 四、还需要额外学习的知识（按优先级）

### 1. C 语言与单片机（与电路基础同步）

先掌握：变量、数组、结构体、函数、指针基础；GPIO 输入输出；定时器和中断基本概念；UART、I²C、SPI；ADC、PWM 的用途；串口打印和基本调试。

不必先啃完厚重的单片机教材。选一种常见开发板，根据官方示例完成"读取传感器—处理数据—显示或上传"即可。

### 2. 数字电子技术与模拟电子技术

**数字电路优先**：高低电平和逻辑电平、上拉下拉、推挽与开漏、常用逻辑门、时序基本概念、为什么不同电压的器件不能直接互连。

**模拟电路优先**：二极管和三极管基本应用、运算放大器基础、电压比较器、稳压/LDO 与 DC-DC 的用途和区别、RC 滤波、去耦电容和旁路电容、ADC 前端基本概念。

初期不需要会设计复杂放大器，但必须能看懂常见外围电路。

### 3. 元器件与数据手册（画 PCB 前必须学）

至少能看懂：芯片供电范围和典型应用电路、引脚定义及输入输出类型、最大额定值与推荐工作条件的区别、电阻功率与电容耐压、元器件封装名称和尺寸、数据手册中的参考设计和布局建议。

> ⚠️ 原理图符号正确 ≠ PCB 封装正确。封装画错、引脚编号对应错误，是新手最常见的报废原因之一。

### 4. EDA、原理图与 PCB 设计

立创 EDA、KiCad 等任选一种，不要在工具间反复切换。完整流程：

**需求与框图 → 选型 → 原理图 → 电气规则检查 → 分配封装 → PCB 布局 → 布线 → 设计规则检查 → 输出制造文件和 BOM → 下单 → 焊接调试**

第一块板重点：

- 先布局，后布线
- 电源入口、主控、传感器和接口按功能分区
- 去耦电容靠近芯片电源引脚
- 电源线和地线不要无理由地过细
- 关注电流的回流路径，而不是只追求"线连上了"
- 接口标明电源、地和信号方向
- 给关键电源和测试信号预留测试点
- 检查封装、极性、连接器方向和丝印
- 板框、安装孔和接口位置要考虑外壳与插拔空间

第一版建议双层板、较大的元器件和连接器，先练手工焊接，不追求极限小型化。

### 5. 焊接、测量与调试

准备：电烙铁及焊接耗材、万用表、可调且带限流功能的直流电源（条件允许时）；示波器和逻辑分析仪后续再考虑。

新板上电顺序（不要"插上看运气"）：

1. 检查焊接、极性和明显短路
2. 测量电源与地之间的阻抗，排查异常
3. 限流上电，观察电流是否异常
4. 先测各电源轨，再测复位、时钟和通信信号
5. 分模块验证，不要一次调试所有功能

## 五、8～10 周安排

| 阶段 | 学习重点 | 必须完成的实践 |
| ---- | ---- | ---- |
| 第 1～2 周 | 电压、电流、功率、KCL/KVL、串并联、分压 | LED 限流、电阻分压测量，学会使用万用表 |
| 第 2～4 周 | C 语言、GPIO、UART、I²C | 开发板读取传感器，并串口输出或屏幕显示 |
| 第 4～5 周 | RC 电路、去耦、电源基础、数据手册 | 确定成品框图、器件清单和连接关系 |
| 第 5～6 周 | EDA、原理图、封装 | 完成扩展板原理图，并逐项核对引脚 |
| 第 6～7 周 | 布局、布线、地回流、DRC | 完成双层 PCB，找有经验的人复查 |
| 第 7～9 周 | 焊接和分模块调试 | 完成上电、供电检查、传感器通信和功能验证 |
| 第 9～10 周 | 问题复盘与迭代 | 修改第二版，补充外壳、文档或联网功能 |

第一版成功后再增加物联网功能（Wi-Fi/蓝牙上传数据、MQTT、TCP/IP、简单服务器端展示）。**先把单机功能调通，再联网。**

## 六、最容易走弯路的做法

- 花几个月纯看《电路》和高数，却不动手
- 第一块板就挑战高速、射频、开关电源或市电
- 只学 PCB 布线，不学原理图和器件选型
- 直接照搬开发板原理图，却不理解供电、启动和去耦
- 忽略数据手册中的参考布局
- 封装、引脚号和接口方向没有复核就下单
- 板子不工作就整体重画，而不是按电源、复位、主控、通信逐层排查
- 同时学多种主控、多个 EDA 软件和多个项目，导致没有完整成品

> 阶段性目标：**第一块板不追求复杂，而要能独立完成"需求—验证—设计—制造—焊接—调试—复盘"的全过程。**完成一次以后，再逐步做独立主控板、低功耗传感器节点和联网设备，学习速度会明显加快。
